v0.2.0 audit - June 16, 2026

Release Readiness Audit

v0.2.0 is a broad public-facing release candidate: the desktop interface has been overhauled, all bundled recipes are available, Windows WSL2/Docker onboarding has been corrected, and the website/docs now match the release claim. The release is close, with Windows acceptance testing still pending before the final live score.

90
Readiness score
Release candidate, not final live release yet.
Automated checks have passed locally, version metadata is aligned, and the remaining blockers are validation and disclosure work rather than known app-code failures.

What Improved

Major UI overhaul The desktop app moved to the Console-inspired redesign with updated dashboard, cards, detail views, onboarding, and shared UI components.
11 games enabled The bundled recipe catalog now exposes Minecraft Java, FiveM, Bedrock, both ARK variants, CS2, Palworld, Project Zomboid, Rust, Terraria, and Valheim.
WSL2/Docker onboarding corrected Windows readiness now accepts the Docker Desktop path where WSL features and default WSL2 are configured but no standalone distro exists.
Smoke-test harness added The core crate now has recipe lifecycle smoke-test support, and the CLI exposes a smoke-test command for Docker-backed validation.
Automated checks passing App checks and website checks have passed locally: Rust tests/clippy, frontend check/test/build, plus website check/build.
Version metadata aligned App package metadata, Tauri config, changelog, website package version, release docs, and audit manifest now agree on v0.2.0.

Remaining Gaps

Windows validation pending The onboarding fix still needs real Windows acceptance testing across WSL disabled, reboot required, Docker installed but stopped, and post-Docker server creation scenarios.
macOS marked experimental Release CI builds macOS ARM and Intel artifacts, but the website intentionally routes macOS users to GitHub Releases until those builds are manually tested.
Recipe coverage exceeds smoke coverage The recipe list is much broader than the manual smoke-test coverage. ARK, Rust, and Valheim should be prioritized because their image tags changed for this release.
Changed-tag smoke follow-up Local optional smoke testing on June 16, 2026 confirmed Valheim reaches ready on sha-732221f4d5b5. ARK hit a SteamCMD app update failure, and Rust cycled through SteamCMD update/startup without reaching readiness before the local run was stopped.
Vite/Node warning remains The website build passes but still emits a Node module.register() deprecation warning from the toolchain.

Evidence

  • App versions are stamped as 0.2.0 across the five release-checked app files.
  • CHANGELOG.md has a v0.2.0 section with the redesign, smoke-test, recipe, and onboarding notes.
  • Recipe default_tag values no longer use the moving latest tag.
  • Website download copy now acknowledges experimental macOS builds without promoting direct macOS asset URLs.
  • Roadmap now presents v0.2.0 as the current release candidate and v0.3.0 remote agent as the next focus.
